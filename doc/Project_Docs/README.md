# Project Docs (актуальные документы)

Эта папка содержит **только актуальные** проектные документы, которые описывают текущую архитектуру и операционные договорённости CodeAI Hub.

## Структура
- `SystemArchitecture/` — системная архитектура и карты компонентов.
- `Stacks/` — стек‑документация по Core/UI/Launcher/провайдерам.
- `AgentPackages_Architecture.md` — архитектура agent packages и точки интеграции.
- `knowledge/` — минимальная база знаний для запуска/эксплуатации.

## Что оставлено намеренно
- `knowledge/ProviderSetupGuide.md` — как установить и аутентифицировать CLI провайдеров.
- `knowledge/Local_Artifacts_Workflow.md` — офлайн‑цикл сборки, локальные артефакты, дисциплина релизов.

## Примечание
Исторические и одноразовые дизайн‑доки, созданные под завершённые рефакторинги, удалены из рабочей структуры и остаются доступными в истории Git.
