# Инструкция по созданию новых релизов CodeAI Hub

## Обзор

Данная инструкция описывает пошаговый процесс создания новых версий:
- **Ядра** (packages/core) - автономный оркестратор
- **Расширения VS Code** (VSIX) - включает webview и standalone UI

## Когда нужно обновлять версии

### Когда обновлять версию ядра (0.1.x):
- Изменения в `packages/core/src/`
- Изменения в API ядра (RemoteBridge, SessionManager, etc.)
- Исправления багов в логике ядра
- Добавление новых endpoints

### Когда НЕ обновлять версию ядра:
- Изменения только в UI коде (`src/client/ui/`)
- Изменения в расширении VS Code (`src/extension-module/`)
- Изменения в документации

### Когда обновлять версию расширения (1.1.x):
- **Всегда**, когда меняется код в `src/` или `packages/core/`
- Изменения в UI
- Изменения в логике расширения
- Обновление версии ядра (даже если код расширения не менялся)
- Обновление версии Launcher (для манифеста)

### Когда обновлять версию Launcher (1.0.x):
- Обновление CEF/Chromium
- Добавление нативных интеграций с ОС (уведомления, hotkeys, tray icon)
- Изменения в IPC между CEF и UI
- Security патчи браузерного движка
- Изменения в window management

### Когда НЕ обновлять версию Launcher:
- Изменения в UI коде — это идёт в бандл расширения
- Изменения в логике ядра — это отдельный процесс
- Стили, React компоненты, бизнес-логика
- Обновления ядра или расширения без native изменений

## Часть A: Обновление и сборка ядра (если нужно)

### A1. Обновить версию ядра

**Файл:** `packages/core/package.json`

```json
{
  "name": "@codeai-hub/core",
  "version": "0.1.1",  ← ИЗМЕНИТЬ ЗДЕСЬ
  ...
}
```

### A2. Пересобрать TypeScript код ядра

```bash
cd packages/core
npm run build
```

**Проверка:** Убедиться что в консоли нет ошибок TypeScript.

### A3. Создать бинарники через pkg

```bash
npm run pkg
```

**Что происходит:**
- Создаются бинарники для всех платформ в `../../doc/tmp/releases/`:
  - `codeai-hub-core-macos-arm64`
  - `codeai-hub-core-macos-x64`
  - `codeai-hub-core-linux-x64`
  - `codeai-hub-core-win-x64.exe`

**Проверка:**
```bash
ls -lh ../../doc/tmp/releases/codeai-hub-core-*
```

### A4. Упаковать бинарник macOS ARM64 в tar.bz2

⚠️ **КРИТИЧЕСКИ ВАЖНО:** Имя файла внутри архива должно быть `codeai-hub-core`, а НЕ `codeai-hub-core-macos-arm64`!

```bash
cd ../../doc/tmp/releases

# Переименовать бинарник временно
cp codeai-hub-core-macos-arm64 codeai-hub-core

# Упаковать с правильным именем
tar -cjf codeai-hub-core-darwin-arm64-0.1.1.tar.bz2 codeai-hub-core

# Удалить временную копию
rm codeai-hub-core
```

**Проверка содержимого архива:**
```bash
tar -tjf codeai-hub-core-darwin-arm64-0.1.1.tar.bz2
```

**Ожидаемый вывод:** `codeai-hub-core` (БЕЗ суффикса `-macos-arm64`)

❌ **НЕПРАВИЛЬНО:** `codeai-hub-core-macos-arm64`  
✅ **ПРАВИЛЬНО:** `codeai-hub-core`

### A5. Вычислить SHA-1 и размер архива

```bash
# SHA-1
shasum codeai-hub-core-darwin-arm64-0.1.1.tar.bz2

# Размер в байтах
ls -l codeai-hub-core-darwin-arm64-0.1.1.tar.bz2 | awk '{print $5}'
```

**Запишите эти значения!** Они понадобятся для манифеста.

### A6. Обновить манифест ядра

**Файл:** `assets/core/manifest.json`

```json
{
  "schema": 1,
  "baseUrl": "https://github.com/OleynikAleksandr/CodeAI-Hub/releases/download/v1.1.7/",  ← НОВАЯ ВЕРСИЯ РАСШИРЕНИЯ
  "platforms": {
    "darwin-arm64": {
      "coreVersion": "0.1.1",  ← НОВАЯ ВЕРСИЯ ЯДРА
      "package": "codeai-hub-core-darwin-arm64-0.1.1.tar.bz2",  ← НОВОЕ ИМЯ ФАЙЛА
      "size": 16249537,  ← РАЗМЕР ИЗ ШАГА A5
      "sha1": "fa946f1b8bdcd42ab8c3a3f539cb7f3f69b1c522"  ← SHA-1 ИЗ ШАГА A5
    },
    ...
  }
}
```

**⚠️ Важно:**
- `baseUrl` должен содержать **версию расширения** (v1.1.7), а не версию ядра!
- `coreVersion` — версия ядра (0.1.1)
- Обновлять нужно все 3 поля: `package`, `size`, `sha1`

## Часть C: Обновление и сборка Launcher (редко)

### Когда нужно обновлять Launcher?

**Launcher обновляется ТОЛЬКО при:**

#### 1. Обновление CEF/Chromium
- Новая версия Chromium Embedded Framework
- Критические security патчи в браузерном движке
- Обновление функций WebRTC, WebGL и других Web API

#### 2. Нативные интеграции с ОС
- **macOS:** Touch Bar, меню в menu bar, dock интеграция
- **Windows:** Taskbar integration, Jump Lists
- **Linux:** Desktop notifications, system tray

#### 3. Изменения в IPC (Inter-Process Communication)
- Новые native API для UI (file dialogs, notifications, etc.)
- Добавление bridge между CEF и Node.js
- Новые security permissions

#### 4. Window management
- Изменения параметров окна (размер по умолчанию, позиция, режим)
- Добавление мультиоконности
- Изменения в обработке deep links

#### 5. CSP и Security политики на уровне CEF
- Обновление Content Security Policy
- Изменения в sandboxing
- Новые разрешения для доступа к ресурсам

### Когда НЕ нужно обновлять Launcher:

❌ **НЕ обновлять при:**
- Изменения в UI коде (`src/client/ui/`) — это идёт в бандл
- Изменения в логике ядра (`packages/core/`) — это отдельный процесс
- Изменения в WebSocket коммуникации — это через core-bridge
- Стили, React компоненты, бизнес-логика
- Обновления ядра или расширения

### Примеры задач требующих обновления Launcher

**Задача 1: Добавить поддержку системных уведомлений**
- Потребуется native API для notifications
- Нужно обновить Launcher → добавить IPC bridge
- UI остаётся в бандле, только добавляется вызов native API

**Задача 2: Добавить hot-key для вызова окна**
- Регистрация глобальных hotkeys — это OS-level функция
- Нужно обновить Launcher → добавить keyboard hook
- UI логика остаётся в бандле

**Задача 3: Добавить drag-and-drop файлов**
- Базовый drag-and-drop работает через HTML5 API (не нужен Launcher)
- Но native file access permissions требуют CEF интеграции
- Нужно обновить Launcher → настроить file access permissions

**Задача 4: Изменить стиль кнопок в UI**
- Это чисто CSS/React изменение
- НЕ нужен Launcher, только пересборка VSIX

**Задача 5: Добавить новый endpoint в ядре**
- Это изменение в `packages/core/`
- НЕ нужен Launcher, только обновление ядра

**Задача 6: Добавить интеграцию с macOS Touch Bar**
- Touch Bar — native macOS feature
- Нужно обновить Launcher → добавить Touch Bar API
- UI описание Touch Bar элементов может быть в бандле

### Частота обновлений

**Типичные частоты:**
- **Ядро:** каждые 1-3 недели (новые фичи, исправления)
- **Расширение:** каждые 1-2 недели (UI улучшения, фичи)
- **Launcher:** каждые 2-6 месяцев (security патчи, нативные фичи)

## Частые ошибки и их решения

### Ошибка: "ENOENT: no such file or directory, chmod"

**Причина:** Внутри архива `tar.bz2` файл называется `codeai-hub-core-macos-arm64` вместо `codeai-hub-core`

**Решение:**
```bash
cd doc/tmp/releases
cp codeai-hub-core-macos-arm64 codeai-hub-core
tar -cjf codeai-hub-core-darwin-arm64-0.1.1.tar.bz2 codeai-hub-core
rm codeai-hub-core

# Проверить
tar -tjf codeai-hub-core-darwin-arm64-0.1.1.tar.bz2
```

### Ошибка: SHA-1 не совпадает

**Причина:** Манифест не обновлён после пересборки архива

**Решение:**
```bash
# Пересчитать SHA-1
shasum codeai-hub-core-darwin-arm64-0.1.1.tar.bz2

# Обновить в assets/core/manifest.json
```

### Ошибка: Версия ядра не обновилась после установки

**Причина:** `baseUrl` в манифесте указывает на старый release

**Решение:** Обновить `baseUrl` в `assets/core/manifest.json` на версию **нового расширения**

## Схема версионирования

### Версии ядра (packages/core):
- **0.1.x** — минорные обновления, исправления, новые фичи
- **0.2.0** — мажорные изменения API, breaking changes
- **1.0.0** — стабильный релиз

### Версии расширения:
- **1.1.x** — минорные обновления, новые фичи
- **1.2.0** — значительные изменения функционала
- **2.0.0** — мажорные изменения, новая архитектура

### Версии Launcher:
- **1.0.x** — bug fixes, минорные патчи
- **1.1.0** — новые native features, IPC обновления
- **2.0.0** — обновление CEF/Chromium на новую мажорную версию

### Правило связи версий:
- **Обновление ядра** → обязательно новая версия расширения
- **Обновление расширения** → не обязательно новая версия ядра
- **Обновление Launcher** → обязательно новая версия расширения (для манифеста)
- **Обновление ядра/расширения** → не обязательно новая версия Launcher

### Независимость компонентов:
```
Launcher (1.0.43) ────┐
                      ├──► VSIX (1.1.7) ──► GitHub Release
Core (0.1.1) ─────────┘
```

- **VSIX** содержит манифесты для Launcher и Core
- Launcher и Core работают независимо друг от друга
- UI бандл (в VSIX) работает с любой совместимой версией Core и Launcher
