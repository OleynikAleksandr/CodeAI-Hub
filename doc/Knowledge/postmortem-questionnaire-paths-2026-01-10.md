# Postmortem — анкета Idea сохранялась в неверные пути

**Date:** 2026-01-10
**Owner:** CodeAI Hub team

## Краткое описание
Анкета и артефакты этапа Idea сохранялись в `.codeai-hub/initiatives/unknown-initiative/runs/000-unknown/...` либо не создавались вовсе. Пользователь получал системное сообщение о том, что контекст initiative/run не получен, и кнопка «Продолжить анкету» показывалась без фактически созданного файла.

## Влияние
- Анкета создавалась в неправильной папке или не создавалась вообще.
- UI показывал некорректную возможность «возобновить» без содержимого.
- Повышалась вероятность потери ответа и путаницы в артефактах.

## Корневые причины
- В событии `session:created` из Core не передавались `initiativeSlug/runSlug/stage`, поэтому UI не мог вычислить правильные пути на старте сессии.
- В UI/контракте присутствовали fallback‑пути, которые маскировали проблему и приводили к сохранению в `unknown-initiative/000-unknown`.
- Auto‑run создавал run асинхронно, а UI ожидал контекст синхронно при запуске анкеты.
- Не было e2e‑регрессионного теста на сценарий «Start Idea → анкета → файл в правильной папке».

## Хронология
- Пользователь сообщил о неверных путях анкеты/артефактов.
- Введены блокировки записи без контекста, чтобы остановить запись в `unknown-initiative/000-unknown`.
- Исправлено формирование `session:created` — теперь контекст передается сразу.
- Подготовлен релиз v1.1.400 с исправлением.

## Что сделали
- Передача `initiativeSlug/runSlug/stage` в `session:created`.
- Удаление/блокировка fallback‑пути для анкеты и артефактов без контекста.
- Обновление release docs и сборка релиза v1.1.400.

## Профилактика
- Добавить e2e‑чек: старт Idea → анкета создается в `.codeai-hub/initiatives/<initiative>/runs/<run>/idea/questionnaire.md`.
- Убрать скрытые fallback‑пути, оставлять явные ошибки с инструкцией пользователю.
- Логировать наличие/отсутствие контекста при старте анкеты и при создании run.

## Итог
Проблема закрыта в v1.1.400. Анкета создается в правильной папке, UI получает контекст сразу после создания сессии.
