## 1. Краткое описание

> Модуль автоматизации процесса разработки, где AI-агенты ведут пользователя через формализованные этапы (Flow), задают вопросы для создания артефактов и гарантируют качество через Structured Outputs.

---

## 2. Проблема

Какую проблему решает этот модуль?

- **Неформализованность процесса**: каждая сессия разработки "придумывается заново"
- **Потеря контекста**: при завершении контекстного окна AI теряется прогресс
- **Зависимость от промптов**: агент следует инструкциям "по желанию", нет гарантий
- **Ручное создание документов**: пользователь сам пишет спецификации, планы, отчёты
- **Отсутствие контроля качества**: нет автоматических гейтов и checkpoint'ов

---

## 3. Решение (высокоуровневое)

Как предлагается решить проблему?

- **Инверсия ролей**: Агент задаёт вопросы → генерирует артефакты → Пользователь утверждает
- **Формализованный Flow**: чёткие этапы с шаблонами артефактов
- **Structured Outputs**: JSON-схемы гарантируют формат ответов агента
- **Автоматическое управление сессиями**: мониторинг контекста, безопасное завершение, отчёты
- **Plan.md как исполняемая спецификация**: агент следует плану, не импровизирует

---

## 4. Ключевые функции

| # | Функция | Описание |
|---|---------|----------|
| 1 | Flow Wizard | UI для выбора и запуска Flow разработки |
| 2 | Артефакт-генератор | Агент создаёт Idea → Spec → Plan через вопросы |
| 3 | Session Manager | Мониторинг контекста, автозавершение, отчёты |
| 4 | Plan Executor | Пошаговое выполнение Plan.md с гейтами |
| 5 | Structured Output Contracts | JSON-схемы для каждого этапа Flow |
| 6 | Progress Tracker | Визуализация прогресса для пользователя |

---

## 5. Пользователи и роли

Кто будет использовать и как?

- **Пользователь**: 
  - Выбирает Flow в UI
  - Отвечает на вопросы агента
  - Утверждает артефакты
  - Визуально проверяет результаты
  - Может прервать (Escape) и скорректировать

- **AI Агент**: 
  - Задаёт вопросы для сбора требований
  - Генерирует артефакты по шаблонам
  - Выполняет Plan.md пошагово
  - Отчитывается через Structured Outputs
  - Автоматически сворачивает сессию при приближении к лимиту

- **Система**: 
  - Хранит шаблоны и схемы
  - Мониторит контекстное окно
  - Валидирует Structured Outputs
  - Сохраняет артефакты и отчёты

## 6. Границы (что НЕ входит)

- Автономное выполнение без участия пользователя (всегда есть checkpoint'ы)
- Поддержка провайдеров без Structured Outputs (Gemini CLI — частично, только инструкции)
- Автоматическое тестирование кода (пока только гейты качества и ручная проверка)
- Knowledge-система (откладывается, требует отдельного исследования)

## История обсуждения (Session 023)

### Ключевые решения

1. **Название модуля**: Project Orchestrator
2. **Flow**: один максимальный, усечённые — позже
3. **Провайдеры**: Claude/Codex через SO, Gemini — инструкции
4. **Хранение**: 
   - Глобальные шаблоны: `~/.codeai-hub/templates/`
   - Проектные артефакты: `<project>/.codeai-hub/`

### Этапы Flow (4 артефакта)

1. **Обсуждение идеи** → Idea.md (этот документ)
2. **Спецификация** → Spec.md
3. **Планирование** → Plan.md
4. **Реализация** → Code + Session Reports

### Сессия как единица работы

- Триггер завершения: 80% контекста (настраивается) + конец микро-задачи + ручная команда
- Резерв 10-20% контекста на отчёт
- Автоматический Session Report через Structured Output
- Восстановление через `must_read` + `resume_from`
