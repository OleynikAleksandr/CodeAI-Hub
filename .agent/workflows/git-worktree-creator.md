---
description: Создает Git Worktree для текущего Workspace с самостоятельным branch
---

Необходимо создать для активного Workspace, в том же дерриктории, что и он сам (т.е. рядом) один Git Worktree с числовым суффиксом ххх - проверив наличие ранее созданных и взяв следующий по порядку номер.
И одновременно создать в новом Git Worktree новый Branch с именем Agent-с числовым суффиксом ххх - проверив наличие ранее созданных и взяв следующий по порядку номер.
