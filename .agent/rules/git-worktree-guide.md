# Параллельная разработка с AI через Git Worktree

Этот документ описывает стратегию "Мульти-Агентной Фабрики", позволяющую запускать несколько независимых AI-агентов (сессий) для работы над одним проектом одновременно, избегая конфликтов файловой системы.

## Проблема
VS Code (и Antigravity) привязывает сессию агента к открытой папке (Workspace Root).
- Нельзя открыть одну и ту же папку в двух окнах и работать в разных ветках (файловая система одна).
- `git branch` переключает файлы в текущей папке, что сломает работу соседнего агента.

## Решение: Git Worktree
`git worktree` позволяет создать **физически отдельную папку** для каждой ветки, связанную с основным репозиторием.

### Схема работы

1.  **Основной репозиторий (Main)**: Место сборки и слияния.
2.  **Рабочее дерево 1 (Feature A)**: Отдельная папка для Агента 1.
3.  **Рабочее дерево 2 (Feature B)**: Отдельная папка для Агента 2.

---

## Инструкция

### 1. Подготовка (в терминале)

Находясь в корне вашего основного проекта:

```bash
# Посмотреть список текущих деревьев
git worktree list

# Создать новую ветку и папку для нее (на уровень выше, чтобы не мусорить в проекте)
# Синтаксис: git worktree add <путь_к_новой_папке> -b <имя_новой_ветки>

git worktree add ../codeai-hub-feature-login -b feature/login-page
git worktree add ../codeai-hub-feature-db -b feature/database-fix
```

Теперь у вас на диске:
```text
/Projects
  /CodeAI-Hub              <-- Основной проект (main)
  /codeai-hub-feature-login <-- Папка для Агента 1
  /codeai-hub-feature-db    <-- Папка для Агента 2
```

### 2. Запуск Агентов

1.  Откройте **новое окно VS Code** с папкой `../codeai-hub-feature-login`.
2.  Запустите Antigravity (Сессия 1).
3.  Агент будет видеть только файлы этой ветки и работать изолированно.

Повторите для второй папки.

### 3. Завершение и Слияние

Когда Агенты закончили работу и сделали `git push`:

1.  Вернитесь в **основное окно** (папка `CodeAI-Hub`).
2.  Удалите рабочие деревья (опционально, чтобы почистить диск):
    ```bash
    git worktree remove ../codeai-hub-feature-login
    git worktree remove ../codeai-hub-feature-db
    ```
3.  Запустите "Merge Agent" в основном окне для слияния веток:
    ```bash
    git merge feature/login-page
    git merge feature/database-fix
    ```

## Преимущества
- **Изоляция**: Агенты не мешают друг другу.
- **Скорость**: Не нужно клонировать репозиторий заново (`git clone`), worktree использует общий `.git` каталог, что экономит место и время.
- **Контекст**: Каждый агент имеет свой чистый контекст и свою задачу.
