# Анкета описания (Description) — Кластер (MVP)

> Заполните ответы максимально конкретно.
> Это входной документ для Idea Collector: агент проверит ответы по контракту, задаст уточнения и только после «ОК/утверждаю» создаст артефакты стадии (включая `idea.md` и `virtual-simulation.md`).
>
> Главный принцип:
> - На этапе **Описание** мы сознательно декомпозируем систему на **модули** (микро‑модули, где это разумно).
> - Каждый модуль имеет **фасад** как единственную точку входа (`facade.<ext>`).
>
> Правила:
> - Пишите по-русски.
> - Не вставляйте большие документы целиком — укажите путь/ссылку и короткую выжимку.
> - Сначала укажите документы для чтения в секции 0 (если проект не новый).
> - Если что-то непонятно — задайте вопрос в «Открытых вопросах» или «Примечаниях пользователя».
